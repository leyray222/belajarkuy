05 — Pertanyaan umum

FAQ

01Apakah BelajarKuy benar-benar gratis?+

Ya — 100% gratis selamanya. Ringkasan, flashcard, kuis, dan AI Tutor tidak pernah terkunci. Tidak ada paywall, tidak perlu kartu kredit.

02Format file apa saja yang didukung?+

PDF, Word (DOCX), PPT (PPTX), Excel (XLSX), teks TXT/MD, audio, video, dan link YouTube. Kamu juga bisa menempel teks langsung.

03Apakah materi saya aman?+

Aman. Materi diproses di browser dan disimpan hanya di perangkatmu (localStorage). Tidak ada upload ke server kami.

04Apa beda "Mode Lokal" dan "AI Online"?+

Mode Lokal memproses langsung di perangkat — gratis penuh, karya mandiri. Jika diberi API key (opsional, ada tier gratisnya), kualitas jawaban jadi jauh lebih pintar secara otomatis.

05Bagaimana menambahkan AI Online?+

Klik ikon pengaturan di dalam aplikasi, pilih penyedia (mis. Google Gemini), tempel key gratis dari aistudio.google.com. Tanpa key, aplikasi tetap jalan di Mode Lokal.
