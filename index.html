FAQ

Apakah BelajarKuy benar-benar gratis?

Ya, 100% gratis selamanya. Semua fitur (ringkasan, flashcard, kuis, AI Tutor) bisa dipakai tanpa biaya. Tidak ada paywall, tidak perlu kartu kredit.

Format file apa saja yang didukung?

PDF, Word (DOCX), PPT (PPTX), Excel (XLSX), teks (TXT/MD), audio, video, dan link YouTube. Kamu juga bisa menempel teks secara langsung.

Apakah data materi saya aman?

Materi kamu diproses di browser dan disimpan hanya di perangkatmu (localStorage). Tidak ada upload ke server kami.

Apa itu "Mode Lokal" dan "AI Online"?

Mode Lokal memproses materi langsung di perangkatmu tanpa perlu internet (kualitas standar). Jika kamu menambahkan API key (opsional, gratis), kualitas jadi jauh lebih pintar secara otomatis.

Bagaimana cara menambahkan AI Online?

Klik ikon ⚙️ di aplikasi, pilih penyedia (mis. Google Gemini), tempel API key gratis dari aistudio.google.com, dan simpan. Tanpa key, app tetap bekerja di Mode Lokal.

Siap Revolusi Cara Belajarmu?

Bergabung dengan ribuan pelajar cerdas. Mulai gratis, tanpa batas.
